# AI-Generated Games & Experiments

HTML mini-games and other interesting apps generated by AI models — a playground for testing (and showing off) what they can do. Just for fun, not a benchmark.

## Entries

- **Claude Opus 5.5 — Pelican Parkour** ([play](https://wang-kaijun.github.io/ai-generated-games/claude-opus-5-5-platformer.html) · [source](./claude-opus-5-5-platformer.html))
  A pelican on a bicycle that escalated into a parkour game, a racing mode, and a 3D dock-runner. Originally created for the [pelican-riding-bicycle](https://github.com/Wang-Kaijun/pelican-riding-bicycle) prompt test; moved here once it outgrew that repo.

## Prompt

The original prompt (English): "generate an svg with a pelican riding a bicycle in html, and add a slider for adjusting riding speed"

## Notes

- Everything here was generated in each model's official agent / harness client.
- The testing process is not rigorous; treat all results as for-fun reference material.
- Feel free to cite anything in this repo; just credit the source.
